## Đôi lời về cái ứng dụng này.

Ứng dụng cho dân tự luyện Kanji. Dựa trên mã nguồn của [dự án Kanji Dojo](https://kanji-dojo.com/).

*Ghi chú: Hiện giờ code đã được và mình đang dùng để ôn tập Kanji cho JLPT luôn. Nhưng mà vẫn đang sửa nốt mấy cái ngôn ngữ giao diện này kia, nên chưa cập nhật đường dẫn để tải về máy.* Mình không dự định đăng tải lên F-Droid, Google Play hay gì đâu vì khá phiền, với lại ứng dụng này về cơ bản chẳng khác gì Kanji Dojo, mình chỉ sửa lại một số điểm:

- Cập nhật để dùng dữ liệu Tiếng Việt.
- Tối ưu hóa ứng dụng: Xóa các phần hỗ trợ các nền tảng khác mà chỉ tập trung vào hỗ trợ Android.

### Features

- Memorize how to write and read kana and kanji
- Vietnamese meanings and Hán-Việt readings for kanji
- Follow JLPT levels or school grades
- Create your own decks to study, more than 6000 characters in total are available
- Use SRS reviewing system to avoid forgetting learned information
- Search letters with the built-in dictionary
- Study words with flashcards
- Available modes to write words and pick correct letter readings
- Works offline
- Android phones and tablets

Repository with dictionary data and parsers here:
[Kanji-Dojo-Data](https://github.com/syt0r/Kanji-Dojo-Data)

## Building

Requirements: JDK 17 and the Android SDK (compile SDK 36).

```bash
./gradlew :app:assembleDebug
./gradlew :app:assembleRelease
```

The debug APK is written to `app/build/outputs/apk/debug/`, the release APK to
`app/build/outputs/apk/release/`. Release builds use `keystore.jks` when it is
present; otherwise they are signed with the debug key. Signing credentials can
be supplied through `KEYSTORE_PASS`, `SIGN_KEY`, and `SIGN_PASS`.

The dictionary database is **not bundled into the APK**. On first launch the
app asks the user to download it or import a data file. The gzipped database is
generated by the data repository; see [data/README.md](../data/README.md).

Set the release asset URL at build time (or edit `AppAssets.AppDataDownloadUrl`):

```bash
./gradlew :app:assembleRelease \
  -PkanjiDataUrl=https://github.com/OWNER/REPO/releases/download/data-v16/kanji-dojo-data-base-v16.sql.gz
```

Without `kanjiDataUrl`, the build only offers file import on first launch.
